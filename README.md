<h2>✦ Content Management</h2>

All major portfolio information is centralized in one file:

src/data/portfolioData.js


This makes the portfolio easy to maintain and update.

You can edit:
👤 Personal information
💼 Professional experience
🎓 Education
🧠 HR skills
🏢 Services
📊 Statistics
📧 Email
📱 Phone
💬 WhatsApp
🔗 Social profiles

Tip: You should rarely need to modify the React components when updating portfolio content.

<h2>✦ Personal Assets</h2>
📸 Profile Photo

Place your professional photograph at:

public/profile.jpg


Then enable it inside:

src/data/portfolioData.js

personal.hasPhoto = true


The Hero and About sections will automatically display the image.

📄 Resume

Replace:

public/resume.pdf


with the actual CV while keeping the same filename.
